# Política de Privacidad - YouTube & Web AdBlocker Pro

**Última actualización:** Agosto 2026

## 1. Recopilación de Información
**YouTube & Web AdBlocker Pro** no recopila, almacena, transmite ni comparte ningún tipo de información personal, datos de identificación, historial de navegación, direcciones IP ni actividad del usuario.

## 2. Permisos del Navegador
Los permisos solicitados por la extensión (`declarativeNetRequest`, `storage`, `tabs`, `scripting`, etc.) se utilizan exclusivamente de manera local en tu dispositivo para:
* Aplicar las reglas de bloqueo de anuncios y scripts publicitarios.
* Salta automáticamente los anuncios en plataformas de video como YouTube.
* Guardar tus preferencias locales de configuración (como activar o desactivar el bloqueador).

## 3. Código de Terceros y Servicios
Esta extensión no utiliza código remoto ni se conecta a servidores externos para enviar analíticas o rastreo de usuarios.

## 4. Contacto
Si tienes preguntas o dudas sobre esta política de privacidad, puedes abrir un issue en nuestro repositorio de GitHub.
